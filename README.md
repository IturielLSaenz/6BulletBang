# 🎯 6BulletBang

6BulletBang is a terminal-based C++ game I'm building to level up my C++ skills 💻🔫
It's still in development, but I'm proud of how it's coming together so far!

## 🚧 Work in Progress
Here’s what’s coming next:

🔁 Core game logic (turn-based system & game state changes)

💰 In-game economy (betting, balance calculations)

🖥️ Terminal UI polish

🌐 Remote access for multiplayer mode

This is a fun side project to improve bit by bit — one bullet at a time 😎

## 🛠️ Installation
### 🧾 Prerequisites
You'll need:

A C++ compiler (e.g., g++)

git installed

A Unix-like terminal (Linux, macOS, or WSL for Windows)

### 🧑‍💻 Clone the repo
```bash
git clone https://github.com/IturielLSaenz/6BulletBang.git
cd 6BulletBang
```
### ⚙️ Build the project
```bash
g++ -o 6bulletbang *.cpp
```

▶️ Run the game
```bash
./6bulletbang
```
